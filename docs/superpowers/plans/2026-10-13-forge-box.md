# FORGE BOX Implementation Plan

**Goal:** Entregar o briefing completo como website estático premium e enviar para brick-teck/crossfit na branch main.

**Architecture:** index.html fornece a estrutura semântica. data.js concentra conteúdo e personalização; main.js renderiza as coleções e compartilha contatos e dialogs. CSS separado entre apresentação, responsive e motion.

**Tech Stack:** HTML5, CSS3, Vanilla JS e Google Fonts, sem build ou dependências de produção.

**Spec:** Briefing fornecido pelo usuário; decisões visuais em DESIGN.md.

## Global Constraints
- Funcionar abrindo index.html e em GitHub Pages com caminhos relativos.
- Marca FORGE BOX, cores e tipografia especificadas no briefing.
- Identificar dados fictícios e fotografias ilustrativas; nunca inventar contatos ou localização.

## Review Focus
- Contato vazio ou inválido abre dialog; válido gera WhatsApp personalizado.
- Periodicidade atualiza todos os preços e seus rótulos de cobrança.
- Abas alternam grade inclusive teclado e sábado.
- Dialog e galeria fecham com Escape e restauram foco.
- Mobile sem overflow; movimento reduzido preserva conteúdo.

## Tasks
- [ ] Criar testes comportamentais antes das interações e confirmar falha na página ausente.
- [ ] Implementar estrutura, ativos locais e todas as seções comerciais.
- [ ] Implementar coleções configuráveis, planos, horários, dialogs, FAQ, menu, lightbox e contatos.
- [ ] Executar testes no navegador, inspeção visual e verificações de sintaxe; corrigir achados.
- [ ] Documentar personalização, inicializar Git, commit e push main; conferir hash remoto.
